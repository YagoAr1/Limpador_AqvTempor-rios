# Limpador_AqvTempor-rios
Sistema básico de limpa de arquivos temporários do seu computador

Dentro da pasta, você vai encontrar as seguintes variáveis:
1 - Pasta, 2- Arquivo

A pasta serve para você navegar no formato string pela os.path.join pois só permite esse formato de dados, dentro
da variável arquivo, ela vai receber a pasta como formato em lista já compactada para ser percorrida no for.
